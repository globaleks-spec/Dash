# Управленческий дашборд продаж АО «Завод Инвертор»

Локальное веб-приложение на Python и Streamlit для анализа бизнес-плана, отгрузок, подписанных контрактов, портфеля проектов, менеджеров, СЭЩ, прогнозов и недельных изменений.

Приложение работает без внешних сервисов. Данные хранятся в локальной SQLite-базе `data/inverter_dashboard.db`.

## Что реализовано

- загрузка `.xlsx` через интерфейс;
- автоматическое обнаружение листов, заголовков и квартальных блоков;
- показ предлагаемого соответствия полей перед загрузкой;
- сохранение исходных значений, формул, форматов и координат непустых ячеек;
- отдельная версия данных для каждой уникальной книги;
- защита от повторной загрузки идентичного файла по SHA-256;
- расчёт плана и факта именно по отгрузке;
- консервативный, базовый и оптимистичный сценарии;
- пустая вероятность по умолчанию без автоматического назначения;
- реестр проектов с ручными корректировками;
- аналитика менеджеров и отдельный раздел СЭЩ;
- контроль дублей и качества данных;
- сравнение недельных версий;
- экспорт текущего реестра в Excel и краткого отчёта в текстовый файл.

Подробный разбор исходной книги хранится только в локальной рабочей копии и не включается в демонстрационную облачную публикацию.

## Приватная демонстрация в Streamlit Community Cloud

Для облачной демонстрации используйте точку входа `demo_app.py`. Она открывает
отдельную синтетическую базу `data/demo_dashboard.db`, показывает заметное
предупреждение о тестовых данных и блокирует загрузку реальных Excel-файлов.
Рабочая база `data/inverter_dashboard.db` исключена из Git.

## Установка на Windows 10/11

1. Установите Python 3.11 или 3.12 с [python.org](https://www.python.org/downloads/windows/). При установке включите `Python Launcher`.
2. Откройте папку проекта в Проводнике.
3. Запустите `install_windows.bat`.
4. После завершения запустите `run_dashboard.bat`.
5. Браузер откроет локальный адрес `http://localhost:8501`.

Ручной вариант в PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Если PowerShell запрещает активацию, выполните один раз для текущего пользователя:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## Первая загрузка

1. Откройте раздел `Загрузка`.
2. Выберите очередной еженедельный Excel-файл.
3. Проверьте список листов и предлагаемое соответствие колонок.
4. Нажмите `Загрузить как новую недельную версию`.
5. Перейдите в `Качество данных` и разберите неоднозначные совпадения.

Исходная книга не изменяется. Ручные исправления сохраняются в отдельной таблице SQLite и применяются поверх очередной версии по стабильному ключу проекта.

## Логика сценариев

- Консервативный: фактическая отгрузка плюс подтверждённые отгрузки.
- Базовый: консервативный сценарий плюс подписанные, акцептованные и прочие активные проекты, умноженные на явно введённую вероятность.
- Оптимистичный: факт плюс весь активный портфель выбранного периода.

Неизвестная вероятность равна `NULL` и даёт нулевой вклад только в риск-взвешенную часть базового сценария. Исходная сумма проекта при этом сохраняется и видна в оптимистичном сценарии.

## Защита от двойного счёта

- квартальные переносы одного проекта не складываются: берётся последняя заполненная стадия;
- фактические частичные отгрузки по кварталам суммируются;
- одинаковые бизнес-ключи внутри одной версии агрегируются по максимальному значению показателя и отправляются на ручную проверку;
- канал СЭЩ определяется по явному упоминанию в исходном тексте и не создаёт отдельную копию суммы.

## Служебные команды

Посмотреть структуру книги:

```powershell
python -m dashboard.cli inspect "C:\путь\к\отчету.xlsx"
```

Импортировать книгу без интерфейса:

```powershell
python -m dashboard.cli import "C:\путь\к\отчету.xlsx"
```

Использовать другую базу:

```powershell
python -m dashboard.cli --db "D:\Dashboard\sales.db" import "C:\путь\к\отчету.xlsx"
$env:INVERTER_DB_PATH = "D:\Dashboard\sales.db"
python -m streamlit run app.py
```

## Автоматические тесты

```powershell
python -m unittest discover -s tests -v
```

Проверяются:

- обнаружение структуры Excel;
- расчёт KPI;
- устранение повторного квартального и строкового счёта;
- сохранение явно введённой вероятности;
- идемпотентная повторная загрузка;
- сохранение отдельных недельных версий;
- правила контроля качества.

## Резервное копирование

Перед крупными изменениями скопируйте файл `data/inverter_dashboard.db`. При работающем приложении также могут существовать служебные файлы `-wal` и `-shm`; для консистентной копии сначала остановите Streamlit.

## Ограничения исходника

- Месячная накопительная линия не строится из квартальных данных путём интерполяции. На главном экране показано честное квартальное сравнение.
- Точная дата остаётся пустой, если в Excel указан только квартал или год.
- Отрасль и прямой канал не назначаются автоматически без явного указания.
- Таблица `ТД Москва Запросы и Заказы` содержит суммы с НДС и поэтому не объединяется автоматически с показателями без НДС.
